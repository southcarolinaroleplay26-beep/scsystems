# Artwork assets

The supplied server artwork is stored here and attached to Components V2 messages automatically.

| Filename | Purpose | Recommended format |
| --- | --- | --- |
| `session-header.png` | Session banner above the session announcement | PNG |
| `footer-banner.png` | Shared banner at the bottom of public bot panels | PNG |
| `punishment-header.png` | Punishment banner above infraction records | PNG |
| `support-header.png` | Supplied support banner above the ticket panel | PNG |

If an asset is missing, the bot keeps the text-and-separator layout and omits just that image.
